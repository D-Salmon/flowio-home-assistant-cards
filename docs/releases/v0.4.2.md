# Flow.io Home Assistant Cards 0.4.2

Cette version ajoute un second tableau de bord complet sans remplacer le modèle HACS existant.

Deux fichiers sont proposés :

- `dashboard-flowio-3.5.1.yaml` : huit vues utilisant les cartes Flow.io installées par HACS ;
- `dashboard-flowio-3.5.1-original.yaml` : copie fidèle du dashboard fourni avec Flow.io-Waveshare 3.5.1.

Les deux modèles peuvent être importés dans des tableaux de bord distincts pour comparer leur rendu avant de choisir lequel conserver. Le dépôt HACS, le nom de la ressource JavaScript et l’installation existante restent inchangés.

HACS installe les ressources frontend. La création d’un dashboard Home Assistant nécessite toujours de coller une fois le YAML choisi dans l’éditeur de configuration brute.
