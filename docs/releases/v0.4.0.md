# Flow.io Home Assistant Cards 0.4.0

Cette version ajoute un tableau de bord complet sous la forme d’une seule carte HACS :

```yaml
type: custom:flowio-dashboard-card
title: Piscine principale
entity_prefix: bassin1
grid_options:
  columns: full
```

La navigation interne regroupe les cartes Piscine, Filtration, Traitement,
Équipements, Sondes, Graphiques, Alarmes et Système. Les onglets visibles et
l’onglet initial sont configurables depuis l’éditeur visuel.

`entity_prefix` est transmis à toutes les cartes internes. Deux instances de
Flow.io peuvent ainsi cohabiter dans Home Assistant avec des préfixes distincts,
par exemple `bassin1` et `bassin2`.

## Compatibilité

- Firmware Flow.io-Waveshare 3.5.1.
- Anciennes cartes et configurations conservées.
- Préfixe par défaut inchangé : `fio`.
- Installation comme dépôt HACS personnalisé de type Dashboard.
