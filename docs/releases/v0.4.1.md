# Flow.io Home Assistant Cards 0.4.1

Cette version corrige l’orientation de la version 0.4.0 : elle ne crée pas de
carte globale ni d’onglets internes. Le paquet HACS conserve les cartes
individuelles et fournit un tableau de bord Home Assistant complet à importer.

Le fichier `examples/dashboard-flowio-3.5.1.yaml` crée huit vues séparées :

- Piscine ;
- Filtration ;
- pH ;
- Désinfection ;
- Oxygène ;
- Équipements ;
- Alarmes ;
- Système.

Avant l’importation, remplacer `entity_prefix: fio` par le préfixe configuré
dans le contrôleur Flow.io. Pour deux piscines, importer le tableau de bord deux
fois avec deux préfixes distincts.

La mise à jour utilise le même dépôt HACS et la même ressource JavaScript que
les versions précédentes. Aucune modification du firmware 3.5.1 n’est requise.
